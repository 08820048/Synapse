## 文件笔记系统功能规划

注意,这个文档中的功能指的是左侧侧边栏中文件列表的相关功能。

### 功能描述
- 左侧文件区域支持显示文件夹和md格式的文件列表,以及子文件夹等基本信息,上方右侧的新建文件和新建文件夹默认直接创建在用户选中的vault根目录下
- 列表中的文件夹的图标使用lucide的folder,笔记图标使用lucide的file-text
- 列表中的文件夹支持鼠标右键菜单,菜单中的功能初步为:
  - 新建文件夹
  - 在Finder中显示
  - 新建笔记
  - 重命名(由于是在文件夹上的右键菜单,所以这里重命名指的是这个文件夹的名称),删除
  - 以上功能对于任何一个文件夹或者子文件夹都同样支持,这是递归性质的功能
- 每一个笔记文件支持鼠标右键菜单,初步功能支持:
  - 重命名
  - 在Finder中显示
  - 移到废纸篓
- 列表区域的文件夹或者笔记之间要支持拖拽移动,比如某个文件夹移动到某个文件夹下,某个文件移动到某个文件夹下等操作。
- 上述所有右键菜单中的每一个功能都是菜单图标+菜单名称的形式,并且移到废纸篓/删除等操作的图标和菜单名称显示为红色。
