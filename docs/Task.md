## synapse 功能任务规划

### v1
- 文件打开支持类似zed或者ob那样的顶部页签管理管理,支持多个文档页签,支持通过页签切换不同的文档内容,页签右侧有一个关闭图标,点击可以关闭当前页签
- 页签鼠标右键菜单支持:关闭、关闭左侧、关闭右侧、关闭全部的基础功能
- 整体UI布局进行重大调整,参考zed编辑器的布局方式,不要用当前这种割裂感很强的左中右三段式,并且还是浮动效果的三段式,三段式可以保留,但是必须是一体化的,左侧栏需要支持展开收起操作,操作按钮图标显示在最顶部标题栏中,也就是Mac中的右上角三个远点的水平对齐的位置。左中右三个区域之间只需要使用zed那样的很细的线条进行区分即可,
- 对于右侧的baklinks侧边栏也要支持展开收起,展开收起的按钮图标放在顶部标题栏做右侧位置,并且顶部标题栏的图标始终保持在一条水平线上进行对齐,不要一些高一些低。

- 然后下方就是文件/文件夹的显示区域
- 你先讲上述UI功能处理好,其中涉及到的搜索、待办和书签功能后续陆续完善。
