# Markdown 脚注、提示块与任务列表规格

## 任务列表

- 支持无序及嵌套任务项的 `- [ ]`、`- [x]`、`- [X]` 语法。
- 阅读状态隐藏 Markdown 列表和复选框源码，显示 16px 原生复选框；已完成项使用弱化正文色。
- 点击复选框会直接在 Markdown 缓冲区中切换 `[ ]` / `[x]`，保持当前光标位置并进入未保存状态。
- 光标位于任务项时恢复现有源码编辑表现；保存后仍写回标准 Markdown，不写入私有格式。

## Obsidian 风格提示块

- 支持 Writ 已识别的 Note、Abstract、Info、Todo、Tip、Success、Question、Warning、Failure、Danger、Bug、Example、Quote 及其别名。
- `> [!TYPE]` 使用类型图标和默认标题，`> [!TYPE] 自定义标题` 显示自定义标题。
- 同一提示块的标题和正文绘制为连续的浅色背景容器，使用类型色左边框；深色和浅色主题使用各自对比度。
- 普通引用块继续保持原有无圆角高对比竖线，不受提示块样式影响。
- 光标进入提示块行时恢复可编辑 Markdown 源码；折叠标记可被识别，但本阶段不新增折叠状态交互。

## 脚注

- 支持正文中的 `[^label]` 引用、`[^label]: 内容` 定义和四空格/Tab 缩进的续写段落。
- 行内引用在阅读状态显示为小号上标；行内代码中的同形文本不被识别为脚注。
- 脚注定义使用独立的小号文本区域、顶部分隔线和固定标签列，并继续呈现定义内容中的粗体、斜体、链接与行内代码。
- 光标进入引用或定义所在行时恢复源码，源码/显示字符映射继续用于鼠标定位和选区。

## 验收

- 自动化测试覆盖已完成/未完成及嵌套任务、提示块默认/自定义标题与连续边界、命名脚注、代码误识别和多段脚注。
- 执行格式化、严格 Clippy、workspace 测试、开发构建和差异检查；不启动应用、不执行截图或自动 UI 操作。
