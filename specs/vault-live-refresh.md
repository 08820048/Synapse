# Vault 外部变更实时刷新规格

## 目标

Finder、终端、下载工具或其他应用改变当前 Vault 时，侧栏文件树应自动更新，不要求重新打开 Vault 或重启应用。

## 功能要求

- FR-1：使用操作系统原生文件系统通知递归监听当前 Vault，不得持续高频轮询。
- FR-2：命令行初始 Vault 和文件夹选择器切换后的 Vault 均启动监听；切换时停止旧监听，旧事件不得刷新新 Vault。
- FR-3：创建、修改、重命名、移动和删除事件触发刷新；纯访问事件不触发扫描。
- FR-4：连续事件使用 180ms trailing debounce 合并，避免批量复制时反复递归扫描。
- FR-5：刷新只更新目录快照，不得重载、覆盖或关闭已打开文档，不得改变未保存缓冲区、光标和脏状态。
- FR-6：清理已不存在文件夹的折叠状态，保留仍存在文件夹的状态。
- FR-7：继续忽略非 Markdown 文件和符号链接。
- FR-8：监听或刷新失败必须显示错误，不得 panic 或丢失编辑缓冲区。

## 验收标准

- AC-1：向 Vault 复制含 Markdown 文件的文件夹，约 180ms 后侧栏显示新内容。
- AC-2：从外部重命名或删除文件，侧栏自动同步。
- AC-3：当前笔记存在未保存修改时外部新增其他文件，文件树更新且当前缓冲区保持不变。
- AC-4：一次复制多个文件只产生合并刷新。
- AC-5：切换 Vault 后修改旧 Vault，当前文件树不响应旧事件。
