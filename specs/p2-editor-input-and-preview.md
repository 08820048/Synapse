# P2 编辑输入与实时 Markdown 呈现规格

## 目标

把中心编辑区从只能接收基础按键字符的展示壳升级为可日常输入的原生 Markdown 编辑器，并同步收敛左上工具栏与搜索入口。

## 功能要求

- FR-1：顶部工作区工具栏由 44px 页签标题栏取代；保留窗口拖拽空区，不再显示 `Synapse / <Vault>`、状态或 Open Vault 操作。侧栏开关位于首个页签左侧，直接显示 Lucide 图标，不绘制背景或圆角容器，并保留至少 40px 点击区域；编辑器底部工具栏移除，Open Vault 保留在空状态和命令面板。
- FR-1a：激活页签使用单一表面，与编辑器背景一致，仅隐藏自身底部分割线；其他边缘保持普通直角页签样式，不绘制任何顶部、底部、外凸或内凹圆角。标题栏父容器不绘制贯穿式底边，底边由左侧控制区、未激活页签和右侧拖拽区分别绘制；所有页签继续保留普通右侧分隔线。激活页签不允许使用底线遮罩、装饰 Canvas 或嵌套背景层。
- FR-2：侧栏搜索入口左侧使用 Lucide `search`，默认文案为 `Search any...`，右侧显示 `⌘K` 快捷键徽标。
- FR-3：点击编辑器任意已呈现文本位置后，光标必须移动到最接近的 Unicode 字符边界。
- FR-4：方向键 Up / Down 按字符列跨行移动；经过较短行后继续保留期望列，Left / Right / Home / End 仍可用。
- FR-5：编辑器接入 GPUI 原生 `EntityInputHandler`，支持中文输入法的 UTF-16 选区、组合文本更新和最终提交。
- FR-6：文件缓冲区与磁盘继续保存标准 Markdown 源码；编辑器显示层实时把标题、列表、引用、代码围栏以及成对的粗体/行内代码标记呈现为阅读样式。无序列表由 GPUI 独立绘制 5px faint 圆形 marker，writ 字形仅作为透明位置映射槽位。
- FR-6a：分割线使用正文列全宽 1px 主题 divider 和上下各 2em 间距，不使用固定字符数量模拟长度。
- FR-6b：连续 GFM 表格行解析为统一列数的 GPUI 表格；分隔行隐藏，表头使用 panel 背景和半粗体，单元格使用 1px 主题边框与 6×10px 内边距。活动行恢复 Markdown 源码以继续编辑。
- FR-7：Markdown 预览隐藏或替换标记后，鼠标点击、输入法范围和源码 Unicode 字符索引必须保持双向映射。
- FR-8：编辑器维护锚点与活动端组成的真实选区；支持鼠标拖选、Shift + 方向键/Home/End 扩展、`Cmd/Ctrl+A` 全选、`Cmd/Ctrl+C/X/V` 复制/剪切/粘贴，并让输入、删除和粘贴替换当前选区。
- FR-9：Markdown 呈现必须使用 writ 的 tree-sitter-md 解析结果，不再通过逐行字符猜测实现；至少覆盖 ATX/Setext 标题、无序/有序/任务列表、引用、分隔线、代码块、粗体、斜体、删除线、行内代码、链接、图片占位和 GFM 表格行。
- FR-10：每个 Markdown 源码行必须通过 GPUI wrapped layout 按编辑区实际可用宽度软换行，动态增加显示高度，不得水平扩张父布局或裁切右侧文字。

## 安全与一致性要求

- SR-1：输入和光标索引统一以 Unicode 字符计数，平台输入协议边界统一转换为 UTF-16，禁止按 UTF-8 字节误删中文或 emoji。
- SR-2：输入法组合文本只能替换平台指定范围或当前标记范围，提交后清除 marked range。
- SR-3：预览层不得改写磁盘格式；保存结果必须仍是用户输入的 Markdown 源码。
- SR-4：本阶段不得通过启动应用、截图或自动 UI 操作进行验证；使用纯函数、状态测试、Clippy 和构建完成非视觉验证。
- SR-5：剪贴板中的 CRLF/CR 换行统一转换为 `\n`，不得丢弃多行 Markdown；复制始终读取源码选区，而不是隐藏标记后的显示字符串。

## 验收标准

- AC-1：界面内不再出现工作区 `Synapse / notes` 标题文案。
- AC-2：搜索入口结构与参考图一致，文案精确为 `Search any...`。
- AC-3：Unicode 范围可被中文文本安全替换，光标落在插入文本末尾。
- AC-4：鼠标点击通过真实 GPUI shaped-line 坐标定位源码光标。
- AC-5：Up / Down 跨长短不一的中文行移动时保留期望列。
- AC-6：`## 中文标题` 显示为不含 `## ` 的二级标题；列表、引用、粗体和行内代码不再直接展示对应源码标记；`-`、`*`、`+` 无序列表统一显示为独立绘制的圆形 marker。
- AC-6a：`---` 分割线在窄窗口、普通窗口和宽窗口中均与正文内容列等宽，颜色跟随主题 line token。
- AC-6b：包含表头、分隔行、正文和转义管道符的 GFM 表格呈现为可辨识的表头/单元格结构；点击正文行后可继续编辑该行源码。
- AC-7：全量格式化、Clippy、测试和开发构建通过，且 `PROGRESS.md` 与当前实现同步。
- AC-8：鼠标可跨行拖选并绘制选区；全选、复制、剪切、单行/多行粘贴和选区替换均走 GPUI 原生剪贴板接口。
- AC-9：`docs/Markdown语法完整性测试.md` 全文可生成一致的解析行、样式运行和 Unicode 源码/显示映射；不支持的扩展语法必须保留源码，不得丢失内容。
- AC-10：长中文、英文、URL 和无空格长标识符都使用 `shape_text` 的宽度约束生成连续视觉行；软换行不写入源码，换行后的鼠标点击、光标、选区和输入法范围继续映射到正确字符。
