# 原生磁性短线笔记目录规格

## 目标

在现有 Rust + GPUI 编辑器中实现文章《Codex同款，从零实现一个磁性短线刻度风格的文章目录》的笔记目录体验，同时保持 Synapse 的原生桌面架构，不引入任何 Web 技术或浏览器运行时。

## 架构约束

- 目录数据只能来自当前 Markdown 文本和现有 writ/GPUI 呈现结果。
- 导航只能使用 GPUI `ListState` 与 Markdown 行索引，不生成 URL 锚点。
- 禁止引入 HTML、CSS、JavaScript、WebView、DOM、IntersectionObserver、Web Audio 或前端组件依赖。
- 目录模型必须按 Vault、笔记路径和文档 revision 缓存；纯光标移动、主题无关刷新不得重新提取标题。
- 本阶段不实现文章中的 Tick 音效，避免为装饰性反馈引入音频运行时或平台分支；如后续需要，必须另行设计纯原生、可关闭的声音服务。

## 功能要求

- FR-1：只提取有效的 H1、H2、H3，包括 ATX 与 Setext 标题；H4–H6、空标题和代码围栏中的伪标题不得进入目录。
- FR-2：标题保留原文顺序、层级和真实 Markdown 行索引；重复标题分别保留并可跳转到各自位置。
- FR-3：目录少于两个有效标题时不显示；扣除侧栏后的编辑器宽度小于 1280px，或正文右侧空白无法同时容纳目录刻度、至少 160px 标题卡片和安全间距时隐藏，禁止把目录向左压入正文。
- FR-4：宽屏目录垂直居中，定位基准必须是正文内容的真实右边缘而不是编辑区中心；正文与 40px 刻度命中栏之间保留 16px 间距，窗口右侧保留 8px 安全间距。
- FR-5：默认状态的所有刻度均为 6.08×1.5px、圆角短线和 0.36 透明度；当前章节保持默认长度，只切换为主题 ink 并提高到完全不透明。
- FR-6：鼠标进入目录后，当前章节高亮让位于鼠标中心。距离中心 0/1/2/3+ 的刻度分别使用 27.52/18.88/12.16/6.08px 宽度，透明度分别为 1/0.72/0.52/0.36；中心刻度高度为 2px。
- FR-7：宽度、高度、透明度和颜色使用 180ms 可中断 GPUI 过渡；宽高缓动等价于 CSS `cubic-bezier(0.2, 0, 0, 1)`，快速反向移动时直接重定向到最新目标。
- FR-8：鼠标只要仍位于整个目录区域内，邻近衰减中心不得在刻度间隙中清空；离开目录后恢复当前章节高亮。
- FR-9：仅鼠标中心刻度显示标题卡片。卡片在右侧空白充足时宽 224px，默认窗口有侧栏时可缩窄但不得低于 160px；卡片始终位于 40px 刻度栏右侧且不侵入正文。卡片包含“章节/小节/段落”层级标签与标题文本，使用 panel 表面、12px 圆角和轻量阴影，并以 150ms 淡入及水平位移过渡显示。
- FR-10：点击任一刻度必须阻止事件传递到编辑器文本命中层，并调用 GPUI `ListState::scroll_to` 把对应标题行置于视口顶部。
- FR-11：编辑器滚动回调必须维护真实可见行范围；当前章节是第一条可见行之前最后出现的目录标题，文档顶部则回退到第一条标题。
- FR-12：目录密度超过 70vh/576px 高度预算时，原生布局应逐步压缩刻度命中行和间距，不创建独立滚动条，也不改变标题顺序。

## 验收标准

- AC-1：包含 H1–H6、Setext、围栏代码和重复标题的测试文档只生成正确的 H1–H3 目录项与行索引。
- AC-2：滚动越过各级标题时，非悬停状态只有正确的当前章节刻度为 ink 色且完全不透明。
- AC-3：依次悬停相邻刻度时，0/1/2/3 距离参数准确，间隙不会导致全部刻度闪回默认状态。
- AC-4：悬停中心项只显示该项标题卡片；离开目录后卡片消失并恢复滚动章节状态。
- AC-5：点击重复标题中的任意一项都跳到其自身行，不会错误跳到同名的第一项。
- AC-6：切换主题、移动光标或切换源码模式不会重复计算未变化文档的目录；修改文档 revision 后目录立即更新。
- AC-7：项目依赖清单中不新增任何 Web、DOM、前端或音频运行时。
- AC-8：默认窗口打开侧栏时，目录刻度左边缘必须大于正文右边缘；标题卡片右边缘不得越过编辑器窗口。空白不足时目录整体隐藏，不能覆盖正文换行、选区或鼠标命中区域。
