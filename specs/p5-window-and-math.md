# P5 默认窗口与数学公式规格

## 默认窗口

- 无参数启动时默认窗口尺寸为 `1809 × 1332`，并在当前可用屏幕区域居中。
- 窗口最小尺寸继续保持 `900 × 560`；当屏幕工作区小于默认尺寸时，由操作系统和 GPUI 按可用区域约束窗口。

## 数学公式语法

- 行内公式使用 `$...$`，例如 `$E = mc^2$`。
- 公式块支持单行 `$$...$$` 和多行形式：

  ```markdown
  $$
  \int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
  $$
  ```

- 转义美元符号、行内代码中的美元符号及普通货币文本不应被误识别为公式。

## 渲染与编辑

- 固定使用纯 Rust `RaTeX 0.1.14` 完成 LaTeX 解析、排版和 SVG 生成，不依赖 WebView、JavaScript、网络服务或系统 LaTeX。
- SVG 嵌入字形路径，通过 GPUI 原生 Image 显示；浅色和深色主题分别使用对应的正文前景色。
- 非活动行中的行内公式替换为与文本基线对齐的 SVG；公式块在正文内容区域内居中并按比例缩小，不主动放大。
- 光标进入行内公式所在行或公式块时恢复 Markdown/LaTeX 源码；点击公式预览会回到对应源码位置。
- 解析或排版失败时不崩溃、不改写磁盘内容，并显示可点击的错误状态以便继续编辑源码。

## 缓存与验收

- 数学 SVG 按 Vault、笔记路径、文档 revision、主题和源码模式失效；普通光标移动复用缓存。
- 自动化测试覆盖默认窗口尺寸、行内/块级语法识别、误识别保护、SVG 生成、错误隔离和缓存失效。
- 本阶段只执行格式化、静态检查、自动化测试和构建，不启动应用、不执行截图或自动 UI 操作；实际排版观感由产品手动验收。
